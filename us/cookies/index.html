Cookie and local storage notice

The approved content configuration does not enable analytics or marketing cookies. Any production notice must be checked against the files actually shipped to visitors.

Last updated 2026-08-11

01

Current intended configuration

No analytics provider is enabled and no marketing technology is authorized by data/analytics-events.yaml. The interface may remember a theme or language choice locally only after legal and technical review confirms the exact mechanism and disclosure.

02

Strictly necessary storage

Storage used only to provide a user-requested setting should be minimized, documented with purpose and lifetime, and rechecked against applicable guidance. It must not be repurposed for tracking.

03

If optional technology is added

Optional analytics or marketing code must not load before valid consent where consent is required. Reject and accept choices must be equally accessible, withdrawal must work, and categories and vendors must match the implementation.

04

Implementation audit

A production build must inventory cookies, local storage, external requests and embedded resources. This page cannot be approved from intended configuration alone.

Contracting notice

No service engagement is formed through this website. The legal contracting party, address, governing terms and applicable tax information will be stated clearly in a proposal before any engagement begins.
